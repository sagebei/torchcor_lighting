Installer .exe Portable .zip
  1. Run the installer. It installs for you alone, with no administrator rights, or for everyone, and adds TorchCor Lighting to the Start menu.

Linux

x86_64 with glibc 2.35+ (Ubuntu 22.04, Debian 12, Fedora 36 or newer)

Ubuntu / Debian .deb Other distributions .tar.gz
  1. Ubuntu or Debian: sudo apt install ./TorchCor-Lighting-*-linux-x86_64.deb adds it to the menu and torchcor-lighting to the PATH.
  2. Other distributions: extract the archive, run torchcor-lighting in it, and install.sh for a menu entry.

SHA-256: .deb · .tar.gz

The builds are not code-signed yet, which is why your system asks once before opening them.

Install from source

Prefer the command line? uv fetches a suitable Python (3.11 or newer) by itself.

Terminal 
$ uv tool install git+https://github.com/sagebei/torchcor_lighting
$ torchcor-lighting

Before your first simulation

Simulations run on a compute machine: this computer or a Linux GPU server over SSH. It needs:

  • Python 3.10 or newer, in its own environment
  • PyTorch built for its GPUs (CPU-only works for small meshes)
  • TorchCor, which the app installs for you in one click
