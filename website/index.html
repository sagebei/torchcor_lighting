Cardiac simulation,
made simple.

TorchCor Lighting is a desktop app for TorchCor. Set up, run and explore GPU simulations of the heart on your computer or a GPU server, in a few clicks.

Download View on GitHub

macOS · Windows · Linux

Support many simulation types.

Electrophysiology

Watch activation spread.

Monodomain or reaction–eikonal models with ten cell models built in. Voltage movies, activation, repolarisation and APD maps, and action potentials wherever you click.

12-lead ECG

Simulate the full ECG.

A ventricular beat and all twelve leads on a CT-based heart–torso model, with the lead-field method. Shown on ECG paper and exported as PNG or CSV.

Mechanics

See the tissue deform.

Inflate, contract or beat an idealised ventricle, or bend the benchmark beam, with hyperelastic myocardium laws and follower pressures.

Electromechanics

Make the heart beat.

Couple activation, cell models, Land contraction and finite-strain mechanics of a four-chamber heart to the CircAdapt circulation, with pressure–volume loops.

Get results in three steps.

  1. 1

    Choose a machine

    This computer or any GPU server over SSH. Every GPU is shown live, and the least busy one is picked for you.

  2. 2

    Set up the simulation

    Choose the kind, the mesh and the parameters. Inputs are checked as you type, and you can sweep any parameter.

  3. 3

    Run and explore

    Follow progress and the log live. When the run finishes, its results open as interactive views.

  • Runs keep going

    Close the app or lose the connection; the run carries on.

  • No black box

    Every run is a plain run.py you can read and re-run.

  • Live GPU telemetry

    Load, memory, temperature and power for every GPU.

  • Free and open source

    MIT licensed and built on TorchCor.
